Combat Helper 是一款低调、高效、兼具极致近战满伤爆发与现代热兵器火控的综合战斗辅助模组，专为 Minecraft 1.20.1 (Forge) 深度打造。

### 起源与设计初衷
本模组最初源于一个纯粹而实际的游戏痛点——在**神话植物学（MythicBotany）**等模组中，终极毕业武器（如仙踪钢剑等）具有极高的攻击速度，人类手指点击根本无法跟上武器的攻速上限以发挥满额输出；而常规连点器不仅无法卡准 CD 导致伤害严重衰减，还会打断特殊武器的充能与剑气释放（如魔力光刃、能量光束等）。
因此，Combat Helper 最初作为一套“毫秒级攻速同步与剑气保护器”诞生。在此坚实基础上，它进一步演进为涵盖弓弩 4 阶微元 Runge-Kutta 抛物线截击自瞄、现代枪械火控套件（TACZ、Point Blank、JEG、Scguns）、自动压枪、空仓防丢包换弹及现代化暗黑抽屉战术控制台的全维度战斗助手。

## 核心功能

### 1. 智能近战攻速同步与剑气光刃满伤释放
- **榨干武器攻速上限**：长按攻击键在冷却槽归零的瞬间精准出刀，无论是神话植物学、植物魔法还是 Better Combat 的超高攻速武器，均可实现 100% 满额物理与横扫伤害输出。
- **保护特殊剑气与能量光束**：完全不同于粗暴的普通连点器，本模组严格遵从物品交互判定，确保按住攻击键时能稳定挥出武器附带的特殊剑气、魔力波与光刃特效。
- **可选无敌帧移除**：支持针对特定战况移除受击生物的伤害免疫无敌帧（0-tick 伤害）。

### 2. 现代枪械战术套件
深度适配 Timeless and Classics: Zero (TACZ)、Point Blank、Just Enough Guns (JEG) 及 Scguns 等现代热兵器模组：
- **准星自瞄与 Triggerbot 自动开火**：准星吸附目标后智能锁定关键部位（支持头部优先爆头），对准目标即可全自动倾泻火力。
- **空仓智能自动换弹 (Auto-Reload)**：
  - **弹药箱与大容量背包弹药识别**：原生支持 TACZ 各型弹药箱（IAmmoBox）及散装子弹，背包持有弹药箱即可无缝触发自动装填。
  - **特殊供弹全兼容**：兼容 JEG（如翡翠块、绿宝石等特殊弹药）等跨命名空间供弹需求。
  - **服务端冷却防丢包保护**：在打光弹匣后加入平稳时间缓冲，避免客户端过快发送换弹网络包导致服务端冷却未归零而被静默丢弃（彻底解决“有动作但子弹不增加、需换第二次”的问题）。
  - **智能空换保护**：背包无备弹或换弹进行中绝不反复重复动作，保持战斗流畅。
- **原厂直瞄基准 (Factory Straight-Aim)**：热兵器默认采用极高初速高平直射逻辑，杜绝抛物线过度仰角。
- **反冲力消除与自动压枪 (Anti-Recoil)**：有效抵消连续射击带来的垂直跳动与视角抖动。

### 3. 远程弓弩自适应预判与物理微元截击
- **4阶微元 Runge-Kutta 弹道解析**：根据武器初速、重力加速度与空气阻力系数，实时演算箭矢三维飞行轨迹。
- **运动动量平滑反向补偿**：针对目标与玩家自身的空间相对位移进行反向补偿，自适应高度差、俯冲与飞行瞄准状态，拉动视角时锁定依然稳固。
- **3D 准星截击预判光圈 (Lead Indicator)**：在敌人行进方向前方动态投射高精度绿色截击引导光圈，助你百步穿杨。
- **满蓄即射 (Auto-Shoot)**：长按使用键拉弓，蓄力满格瞬间自动放箭。
- **免重力弓支持**：内置《额外植物学》百中弓（Failnaught）等零重力直瞄武器白名单，支持自定义扩展。

### 4. 三种目标搜索与智能吸附模式
- **模式 1：准星悬停自动锁定**：准星对准生物并在其身上停留 N 秒（可精细配置 0.1~3.0s）后自动激活吸附锁定。
- **模式 2：始终自动锁定**：战斗状态下自动寻找并锁定最近目标；支持在手持武器时由玩家自由滑动微调视角。
- **模式 3：手动按键模式**：完全由玩家按快捷键（默认 R 键 / 鼠标中键）主动接管锁定。
- **多部位自瞄**：
  - HEAD：头部优先（枪械/狙击爆头）；
  - TORSO：胸口躯干（稳定输出）；
  - ADAPTIVE：近距离爆头、远距离瞄准躯干的智能动态切换。

### 5. 现代暗黑战术控制台 (Side-Drawer Console)
使用 Configured 模组设置按钮即可随时呼出：
- **四大战术抽屉选项卡**：
  - [锁定]：搜索距离、视角转向平滑度、部位选择、搜索模式配置；
  - [弹道]：初速微调、重力参数、抛物线/截击光圈开关、距离/血条标牌；
  - [特征]：已存武器弹道特征库全景。支持按时间/按字母正倒序排序，搭载单页 15 条分页限制，即便上千条特征数据也丝滑流畅；
  - [名单]：免重力弓、攻击黑名单、攻击白名单、排除实体四大分类一键分段直切。
- **极简一键录入**：
  - 主手手持武器即可直接一键点击“+ 加入名单 / - 移出名单”；
  - 准星瞄准目标实体（如村民、宠物）即可一键将其录入排除黑名单。

### 6. 实时悬浮监控小窗 (Tactical HUD Overlay)
游戏内按 U 键可随时呼出/隐藏 HUD 战术小窗：
- Tab 0：监控当前主手武器的实时初速、重力值、预计飞行耗时、蓄力百分比与直瞄状态；
- Tab 1：战术滑条快速调整吸附距离、转速，一键切换部件与自瞄模式。

### 7. 全局 3 秒高危操作二次确认机制
为彻底杜绝战斗或调整配置中的误触：
- **单项删除红 X 按钮**：首次点击后按钮自动展开加宽并显示红色确认提示，3 秒内再次点击方可执行删除，超时自动复原。
- **特征档案重置 / 清空特征库**：首次点击触发二次确认警示。
- **名单清空 / 恢复默认名单**：双键位均配有二次点击确认。
- **控制台重置当前页**：首次点击提示并在按钮上变为红色确认状态，防止误触导致整页参数被重置。

## 按键绑定

可在原版游戏内 **选项 -> 控制 -> 按键绑定 -> Combat Helper (战斗助手)** 中自由设置：

| 按键项名称 | 默认按键 | 功能描述 |
| :--- | :---: | :--- |
| **锁定/吸附目标** (`key.autoattacker.lock_on`) | R / 鼠标中键 | 主动激活/切换敌对生物锁定吸附 |
| **战术监控面板 / 调试小窗** (`key.autoattacker.debug_panel`) | U | 快速开关屏幕上的实时弹道监视小窗 |

## 配置参数详解

配置文件位于 `.minecraft/config/combathelper-client.toml`（推荐直接在游戏内通过控制台或 Configured 调整）：

```toml
[General_Settings]
    # 模组总开关
    enableMod = true
    # 自动近战攻击 (蓄力满格自动出刀)
    enableAutoAttack = true
    # 自动拉弓射箭 (蓄力满格自动释放)
    enableAutoShoot = true
    # 枪械空仓自动换弹
    enableGunAutoReload = false
    # 枪械准星对准自动开火 (Triggerbot)
    enableGunTriggerbot = true
    # 枪械自动压枪 / 反冲力消除
    enableGunAntiRecoil = false
    # 自动搜索锁定模式: HOVER_TIMED (悬停定时), ALWAYS_AUTO (始终自动), DISABLED (关闭/纯手动)
    autoSearchMode = "HOVER_TIMED"
    # 准星悬停自动锁定延迟 (秒)
    autoSearchHoverDelay = 0.5

[Lock_On_Settings]
    # 是否开启视角锁定吸附
    enableAimAssist = false
    # 吸附搜索最大距离 (格)
    aimAssistRange = 64.0
    # 视角平滑转动速度 (0.05 ~ 1.0)
    aimAssistSpeed = 0.25
    # 锁定部位: HEAD (头部/爆头), TORSO (胸口躯干), ADAPTIVE (自适应)
    targetPart = "HEAD"
    # 抛物线预览样式: PARTICLE_CHAIN (3D光束链), HUD_RETICLE (2D准星), BOTH (双显), OFF (关闭)
    trajectoryStyle = "PARTICLE_CHAIN"
    # 启用准星 3D 截击预判引导光圈
    enableLeadIndicator = true
    # 显示目标头顶精确距离
    showDistance = true
    # 显示目标血条
    showHealthBar = true

[List_Settings]
    # 免重力直线射击武器 ID 列表
    zeroGravityBows = ["extrabotany:failnaught"]
    # 自动攻击黑名单 (物品 ID 或 #标签)
    blacklist = []
    # 自动攻击白名单 (物品 ID 或 #标签)
    whitelist = []
    # 实体排除名单 (不会被锁定或自动攻击，如村民、盔甲架)
    entityBlacklist = ["minecraft:villager", "minecraft:armor_stand"]
```

## 模组兼容性

| 模组名称 | 兼容状态 | 特殊支持说明 |
| :--- | :---: | :--- |
| **MythicBotany (神话植物学)** | 兼容 | 榨干高攻速武器 DPS 上限、稳定触发魔力光刃与剑气 |
| **Timeless and Classics: Zero (TACZ)** | 兼容 | 自动直瞄、Triggerbot、压枪、各型 AmmoBox 弹药箱识别与换弹防丢包 |
| **Point Blank (零点)** | 兼容 | 自动直瞄、Triggerbot、换弹检测 |
| **Just Enough Guns (JEG)** | 兼容 | 绿宝石块等特殊供弹解析、换弹状态防死锁 |
| **Scguns** | 兼容 | 热兵器识别与开火按键适配 |
| **Better Combat (更棒的战斗)** | 兼容 | 连击动作与横扫攻速判定毫秒级帧同步 |
| **ExtraBotany (额外植物学)** | 兼容 | 内置百中弓 (Failnaught) 零重力直瞄支持 |
| **Configured** | 兼容 | 支持通过游戏内模组菜单一键唤醒现代化战术控制台 |

## 安装指南

1. 确保客户端安装了 Minecraft 1.20.1 以及 Forge 47.1.0 或更高版本；
2. 下载并安装喜爱的战斗、魔法或枪械模组（如神话植物学、TACZ 等）；
3. 将编译生成的 `autoattacker-1.0.0.jar` 放入 `.minecraft/mods` 文件夹；
4. 启动游戏，在游戏内享受战斗助手带来的流畅体验。
